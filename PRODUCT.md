# Alina

Alina is a school timetable builder inspired by Chronexa. Its users need to create feasible weekly class schedules while respecting teacher availability and avoiding clashes. The first milestone is a local, Rust-based application for entering school data and generating a timetable. The app must report incomplete schedules honestly. Assumptions: English-language interface, single-user local use, and starting with a compact timetable model while broader Chronexa compatibility is developed.
